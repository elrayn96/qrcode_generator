# Registos de decisões arquitecturais
| ID | Decisão aceite | Justificação |
|---|---|---|
| ADR-01 | Monorepo | Coordenação de contratos e versões |
| ADR-02 | HTML/CSS/JS puro | Conhecimento e dependências reduzidas |
| ADR-03 | Kotlin/Compose/Material 3 | UI declarativa moderna |
| ADR-04 | Go net/http + Python FastAPI/Uvicorn/Segno/Pillow | Aprender concorrência e separar renderização |
| ADR-05 | REST inicial | Simplicidade; gRPC experimental posterior |
| ADR-06 | Firebase Auth e Firestore | Identidade e metadados |
| ADR-07 | Chaves públicas/privadas | Integrações distintas; públicas não constituem autenticação forte |
| ADR-08 | Cache Go, Token Bucket, quotas Firestore | Limites e aprendizagem |
| ADR-09 | QR estático, histórico local | Sem redireccionamento ou persistência de conteúdos |
| ADR-10 | Conceito B, temas e i18n | Identidade e acessibilidade |
| ADR-11 | GitHub Actions, Docker adiado, alojamento opcional | Portefólio e recursos limitados |

Para alterações futuras: registar contexto, alternativas, decisão, consequências, estado e data. Detalhes de parâmetros, bibliotecas de teste e contratos permanecem propostas até revisão.
