Tipografia: corpo 16 px/sp, secundário 14, títulos 20–32; não reduzir texto para encaixar. Web rem e Android sp; alvos 44 CSS px recomendados e 48 dp Android. Contraste WCAG AA: texto normal 4,5:1, grande 3:1, componentes relevantes 3:1. Validar combinações efectivas. Espaçamento base 4; raios 8/12/20 como proposta. Temas claro/escuro/automático e persistência local. QR independente do tema; margem silenciosa de quatro módulos para QR convencional. Não inverter automaticamente; avisar sobre compatibilidade. Logótipos e formas não devem comprometer padrões funcionais.
